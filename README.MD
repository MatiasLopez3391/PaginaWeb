# F97 Software | Sitio Web Institucional

> **Potenciamos tu negocio con soluciones tecnológicas a medida.**

## Descripción

Este repositorio contiene el desarrollo del sitio web institucional de **F97 Software**.

El objetivo principal del proyecto es crear una página que represente la identidad de la empresa y funcione como un canal de presentación y contacto con potenciales clientes.

A medida que el proyecto evolucione, el sitio podrá incorporar nuevas secciones como presentación de servicios, portafolio de proyectos, clientes, metodología de trabajo y otros contenidos institucionales.

---

## Objetivos del proyecto

* Diseñar una imagen profesional para F97 Software.
* Presentar los servicios ofrecidos por la empresa.
* Mostrar proyectos y trabajos realizados.
* Dar visibilidad a clientes y casos de éxito.
* Facilitar el contacto mediante redes sociales y otros canales oficiales.
* Construir una base escalable para futuras funcionalidades.

## Flujo de trabajo con Git

* La rama `main` contendrá únicamente versiones estables.
* Cada nueva funcionalidad deberá desarrollarse en una rama independiente.
* Todo cambio deberá integrarse mediante una Pull Request.
* Evitar realizar commits directamente sobre `main`.

### Convención de ramas

```text
feature/nombre-funcionalidad
```

Ejemplos:

```text
feature/navbar
feature/contacto
feature/footer
feature/proyectos
```

### Convención de commits

* `feat:` Nueva funcionalidad.
* `fix:` Corrección de errores.
* `docs:` Cambios en la documentación.
* `style:` Cambios de formato o estilos.
* `refactor:` Refactorización del código.
* `chore:` Tareas de mantenimiento.
